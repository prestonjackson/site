Welcome!

I'm Preston Jackson.

I'm exploring collaboration and 3D modeling in local first development, especially as these are related to 3D modeling.

After years of web development using the latest frameworks, languages, and build environment, I'm building Doggedly in the simplest way I possibly can:

  • Frontend: HTML for markup, Markdown for content, CSS for styling, Javascript for interaction. I am leaning on browser-common web technologies like WebRTC, WebGPU, and Web Crypto. But building the rest from scratch.
  • Backend: Apache for the webserver and Python for server-side scripting
  • Database: Simply using the filesystem for data storage
  • OS: macOS for local development and testing, and Debian for public hosting.

Expect rough edges as we go along!
